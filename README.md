## About

Computer Science graduate focused on building **AI-powered, data-driven and production-oriented software systems**. My work spans **Python, SQL, data engineering, machine learning, deep learning, Generative AI, Retrieval-Augmented Generation (RAG), FAISS, Hugging Face and computer vision**.

I enjoy taking problems from **data preprocessing and system design through model development, evaluation and deployment**, with an emphasis on maintainability, reproducibility and measurable impact.

My engineering interests include:

- **Data Engineering:** ETL, data processing, data modeling and data warehousing

### Diffusion-Based Data Harmonization Across Multiple Oral Cancer Imaging Devices

A diffusion-based image-harmonization framework designed to standardize oral-cancer images collected across multiple imaging devices while preserving clinically relevant visual information.

| Dimension | Details |
|---|---|
| **Stack** | Stable Diffusion · ControlNet · LoRA · ESRGAN |
| **Scale** | Multi-device medical-image harmonization workflow |
| **Performance** | **98.70% accuracy · 0.9864 F1 · 0.9871 AUC · 0.96 IoU** |
| **Security** | Preservation-focused medical-image transformation workflow |
| **Impact** | Reduces device-related visual variation for more consistent downstream analysis |
| **Repository** | [GitHub](https://github.com/Mritunj-ya) |

**Research scope**

- Developed a diffusion-based harmonization framework for oral-cancer images acquired from multiple imaging devices.
- Combined Stable Diffusion, ControlNet, LoRA and ESRGAN in the image-processing workflow.
- Reported 98.70% accuracy, 0.9864 F1-score, 0.9871 AUC and 0.96 IoU.

**Publication:** DOI `10.1109/AESPC67542.2025.11326718`

</details>
