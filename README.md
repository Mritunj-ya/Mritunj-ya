About
Computer Science graduate focused on building AI-powered, data-driven and production-oriented software systems. My work spans Python, SQL, data engineering, machine learning, deep learning, Generative AI, Retrieval-Augmented Generation (RAG), FAISS, Hugging Face and computer vision.
I enjoy taking problems from data preprocessing and system design through model development, evaluation and deployment, with an emphasis on maintainability, reproducibility and measurable impact.
My engineering interests include:
Software Engineering: modular architecture, APIs, automation, version control and scalable application design
AI / ML: classical ML, deep learning, computer vision, GANs and diffusion models
Generative AI: RAG pipelines, semantic search, embeddings, vector databases and LLM inference
Data Engineering: ETL, data processing, data modeling and data warehousing
Product Engineering: converting research ideas into usable, measurable and deployable applications
